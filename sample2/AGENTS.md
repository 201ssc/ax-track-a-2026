# sample2 작업 진입 규칙

`sample2/`에서 조사·설계·수정할 때 먼저 [INDEX.md](INDEX.md)를 읽는다. 인덱스의 작업별 표를 따라 관련 규칙, 코드, 완료 확인 방법을 확인한다. 이 파일은 읽기 경로만 안내하며 제품 규칙을 중복 정의하지 않는다.

- 사용자의 최신 명시적 지시가 문서보다 우선한다. 현재 규칙과 코드가 다르면 어느 쪽이 구현 사실이고 어느 쪽이 목표인지 구분한다.
- [HANDOFF.md](HANDOFF.md)에서 진행 상태를 확인한다. 문서 작성 완료를 기능 구현 완료로 해석하지 않는다.
- 가계부 참고자료는 [참고 분석](docs/reference-account-book.md)의 외부 원본 링크에서 확인한다. 이 공유본에는 `sample/`을 복제하지 않았다. 원본의 구조·규칙을 다이어리에 자동 적용하지 않는다.
- 현재 문서 체계는 개인 MVP와 첫 채팅 도구의 범위를 정리한 것이다. 미정 기술 선택이나 기능 확장을 이미 승인된 구현으로 취급하지 않는다. 단, 사용자가 요청한 범위 안의 통상적인 구현 선택은 [개발 규칙](docs/development-rules.md)에 따라 판단한다.
- 기존 수정·미추적 파일을 보존하고 작업 전 상태를 확인한다. 별도 요청 없는 커밋·푸시·외부 배포는 하지 않는다.
- 작업을 마칠 때 관련 규칙, 인수인계의 구현 상태, 실행한 검증 결과를 맞춘다. 상세 절차는 [개발 규칙](docs/development-rules.md)과 [검증 기준](docs/verification.md)을 따른다.
