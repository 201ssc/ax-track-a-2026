# 하루의 결 · UI 기준

2026-10-23 사용자 승인: shadcn/ui를 참고해 흰색·회색 바탕, 얇은 테두리, 통일된 버튼과 입력창, 초록색 강조색으로 변경한다. 휴대폰 기본 폭과 기존 기능·저장 데이터를 유지한다.

## 참고와 확인 범위

- 참고: [shadcn/ui](https://ui.shadcn.com/), [컴포넌트](https://ui.shadcn.com/docs/components).
- Firecrawl로 1440×1000 데스크톱 뷰포트의 전체 페이지를 캡처하고 실제 이미지를 확인했다. [확인한 화면](design/reference-desktop.png).
- 관찰: 흰색 배경과 카드, 옅은 회색 면, 얇은 회색 테두리, 검정에 가까운 본문, 둥근 버튼과 카드, 단순한 선 아이콘. 추출된 기본 글꼴은 Geist다.
- 참고 사이트의 모바일 배치나 상호작용을 그대로 복제했다는 의미는 아니다. 이 앱은 기존의 최대 430px 휴대폰 배치를 사용한다.
- 정적 HTML/CSS/JavaScript에 시각 규칙을 적용한다. 실제 shadcn 컴포넌트 설치나 프레임워크 전환은 이번 작업에 포함하지 않는다.

## 이 앱에 적용하는 값

다음은 참고 화면을 바탕으로 정한 앱 전용 값이다. 사이트 CSS의 정확한 복제값은 아니다.

| 역할 | 값 |
| --- | --- |
| 앱 배경 / 카드 | `#ffffff` |
| 보조 면 / 완료 면 | `#f4f4f5` / `#fafafa` |
| 본문 / 보조 글 | `#18181b` / `#71717a` |
| 테두리 | `#e4e4e7` |
| 강조 / 강조 배경 | `#237454` / `#edf7f1` |
| 실천 / 미실천 / 미기록 | `#488569` / `#c69a6b` / `#e4e4e7` |
| 카드 / 입력창 모서리 | 14px / 8px |
| 기본 여백 단위 | 4px, 주요 간격 8·12·16·20·24px |
| 본문 / 입력 글자 | 13px / 14px |
| 페이지 제목 | 24px |
| 글꼴 | 운영체제 한글 산세리프, 외부 글꼴 요청 없음 |

## 화면 규칙

- 주 메뉴는 화면 하단 고정 탭 4개로 배치한다. PC의 휴대폰 미리보기에서도 앱 폭 안에 맞추고, 본문 아래 여백과 안전 영역을 확보한다. 알림은 탭 위에 표시한다.
- 홈 제목과 일정은 흰 카드 안에 둔다. 제목은 진한 초록색과 굵기로 구분하고 별도 설명 표제는 추가하지 않는다.
- 루틴 카드는 선 아이콘, 기록 수, 작은 진행 막대, 펼치기로 구성한다. 완료 목차와 하위 항목은 회색으로 남아 편집 가능하다.
- 날짜 선택기·달력·체크박스·선택 버튼·기본 버튼의 선, 높이와 모서리를 맞춘다. 미래 조회와 기존 기록 가능 날짜 규칙을 유지한다.
- 기록창은 휴대폰 안에 들어오는 중앙 대화상자로 유지한다. 명확한 제목, 구분선, 입력 영역, 저장/닫기 버튼을 사용한다.
- 채팅과 관리 화면은 같은 입력·버튼 규칙을 사용한다. 목데이터 표시와 변경 확인 과정은 유지한다.
- 항목 관리는 이름·응답 방식·⋯ 메뉴가 있는 한 줄 목록으로 압축한다. 이름은 바로 수정할 수 있고, 수정·중지·이동·삭제는 메뉴에 모은다. 기본 행 높이는 51px이며 긴 이름은 필요할 때만 줄바꿈한다. 메뉴는 하단 탭과 겹칠 때 위로 펼친다.
- 리포트는 흰 카드와 작은 지표를 사용한다. 기존 `5/1/0` 표기와 색상 구분, 회고 전용 목록을 유지한다.
- 이미지 에셋은 화면 구현에 필요하지 않다. 아이콘은 코드 안의 작은 SVG를 사용한다.

## 검증

320·390·1440px에서 넘침, 입력창, 홈/달력, 리포트/관리/채팅을 확인한다. 기존 브라우저 기능 검사로 기록·제목 연결·일정·저장 실패 처리의 유지를 확인한다. 이 문서의 UI 승인 당시에는 저장 방식을 유지했다. 현재 저장 경로·초기화 정책은 이후 [제품 규칙](docs/product-rules.md)과 [HTTP 계약](docs/http-contract.md)을 따르며 같은 시각 규칙을 유지한다.
