# ax-track-a-2026

2026 AI 서비스 엔지니어링 트랙A 개인 학습 저장소입니다.

## 학습 목표

### 관심 트랙 후보
- AI 서비스 유지보수(운영)와 비용 효율화 — 토큰·인프라 비용 최적화, 안정적인 서비스 운영

## 진행 중인 프로젝트

### AI 에이전트 기반 학습 커리큘럼 서비스

학습자의 진단 결과를 바탕으로 학습 커리큘럼을 제안하는 AI 에이전트 기반 서비스를 개발하고 있습니다. 현재는 서비스 흐름과 초기 프로토타입을 설계·검토하는 단계입니다.

- [IRUO UI 검토 자료 — 학습할 표현을 오늘 계획에 담기](projects/iruo/README.md): 예시 데이터를 사용한 모바일 화면 이미지 2장과 기능 소개입니다. 프로젝트의 일부 기능만 담았습니다.
